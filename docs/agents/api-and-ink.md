# musicus-api crate: DTOs and ink format

Crate `crates/musicus-api`: deps serde + postcard only, no I/O, compiles for native and wasm32 (INV-14, d-shared-types).

## DTO conventions (`dto.rs`)

- `Id = i64`. Timestamps i64 Unix seconds. Dates `Option<String>` `YYYY-MM-DD`.
- `Role` serialises lowercase; ordering Member < Librarian < Admin; `can_manage_library()` = librarian|admin; `is_admin()`.
- Error body for every non-2xx (except 409 page conflict and 304/204): `ApiError {error, code, args, message}` (a-error-codes, R-I18N-004), e.g.
  `{"error":"bad_request","code":"password_too_short","args":{"min":8},"message":"the password needs at least 8 characters"}`.
  `error` = generic class of the status (`not_found`, `unauthorized`, `forbidden`, `bad_request`, `conflict`, `unprocessable`, `payload_too_large`, `unsupported_media_type`, `precondition_required`, `too_many_requests`, `internal`); `code` + `args` = `error::ErrorCode` (`#[serde(flatten)]`, adjacently tagged; unit codes have no `args`); `message` = `code.to_string()`, English, for API users/logs only — the web client renders its own text (`musicus-web/src/errors.rs`). Build with `ApiError::new(class, code)`.
- `ErrorCode` (`error.rs`): 59 stable snake_case codes, never renamed or reused (changed meaning = new code). General: `not_found`, `unauthorized`, `internal`, `payload_too_large {max_bytes}`, `too_many_attempts {minutes}`, `csrf_missing`, `librarian_only`, `admin_only`, `already_exists`, `in_use_or_unknown`, `field_empty {field}`, `field_too_long {field, max}` (`Field`: name, family, username, display_name, title, subtitle, composer, arranger, genre, notes, archive_number, tag, label, date, pattern, instrument_word, alias). Accounts: `wrong_password`, `password_too_short {min}`, `password_too_long {max}`, `username_invalid`, `cannot_lock_out_self`, `user_disabled`. Library: `too_many_tags`, `too_many_instruments`, `unknown_key {key}`, `too_many_voices`, `voice_too_long {voice, max}`, `upload_interrupted`, `not_pdf`. Layout: `systems_not_detected`, `correction_too_many_bands {max}`, `correction_bounds_count|range|order` (`PageCorrection::validate` returns the code). Annotations: `unknown_programme`, `copy_from_other_part`, `part_has_no_file`, `page_count_changed`, `if_match_required`, `if_match_invalid`, `invalid_ink {reason: InkError}`. Programmes: `date_format`, `too_many_pieces {max}`. Import: `invalid_pattern {reason: PatternError}`, `invalid_path {path}`, `not_pdf_name {path}`, `too_many_files {max}`, `invalid_file_hash {path}`, `file_changed`, `item_count {max}`, `unknown_items`, `import_committed`, `unknown_score`, `unknown_instruments`, `unknown_instrument`, `file_not_uploaded {path}`, `undo_annotated {pieces}`, `undo_changed {pieces}`, `not_in_batch`, `duplicate_in_library {title}`, `duplicate_in_batch {path}` (staged-file problems), `import_blocked {note: Note?}`. `unknown` = `#[serde(other)]`: a code without args from a newer server (with args serde fails; the client then shows the body's `message`). `examples()` holds one value per code (test `examples_cover_every_code`).
- 409 on page save: body `PageConflict {current_revision}` (not ApiError).
- Whole-list replacement uses `IdList {ids}` with PUT (idempotent).
- `UpdateUser`, `UpdateAnnotationSet`: absent fields = unchanged. `UpdateAnnotationSet.programme_id: Option<Option<Id>>` via `double_option`: absent = unchanged, `null` = unlink, number = link (unit test `programme_link_distinguishes_absent_and_null`).
- `ScoreInput.archive_number`: blank ⇒ None (`blank_is_none`); `Score.archive_number` (`#[serde(default)]`).
- `Score.parts` contains only parts readable by the requester, sorted by `naming::natural_cmp` of `display_name`; `Part.file` = current `FileVersion` or None.
- `Part {label: Option (custom name), display_name (always set: custom or derived), voices: Vec<String> (stored order, maybe empty), transposition: Option<String> (key code or legacy text)}`. `PartInput.label`/`transposition`: blank ⇒ None (`blank_is_none`); `voices` (missing/null ⇒ `[]`) is a list whose entries may be JSON strings or numbers, cleaned by `naming::clean_voices` during deserialisation (`voice_list`; test `part_input_accepts_blank_label_and_numeric_voices`). The old single `voice` field is gone (clean switch, nothing released; serde ignores it like any unknown field, a-part-voices).
- `AnnotationSet.file_sha256/file_version` = the version the set is bound to (compare with `Part.file.version` to detect outdated sets); `pages` = saved pages with revisions.
- Constants: `CSRF_HEADER = "x-musicus-csrf"`, `SESSION_COOKIE = "musicus_session"`.

- `CurrentUser.reader: layout::ReaderSettings` (`#[serde(default)]`); system layout types, reading sequence and view
  planner live in `layout.rs` (described in `layout.md`).

Adding an endpoint: request/response structs here → handler in server → client helper call. Keep field names stable (future app).

## Part names and keys (`naming.rs`, a-part-names, R-LIB-010, R-LIB-011)

- `part_name(custom, instrument_names, key, voices)`: trimmed custom name if non-empty, else `derived_name`: instrument names sorted by `natural_cmp`, case-insensitively deduped, joined `" / "` (none ⇒ `Part`), `+ " in " + key_name(key)`, `+ " " + voices joined with VOICE_SEPARATOR " & "` (stored order, blanks skipped); nothing at all ⇒ `Unnamed part`. Examples: `Trumpet in B♭ 1`, `Flute / Piccolo`, `Horn in F 3a`, `Klarinette 1 & 2`, `Flöte / Oboe 1 & 2`, `Trombone 1 & 2 & 3`, `Part 2`.
- `clean_voices(list)`: each entry split at `&` (the name separator), trimmed, blanks dropped, duplicates ignoring case dropped (first kept), order kept. Limits `MAX_VOICES` = 10, `MAX_VOICE_CHARS` = 20 (checked by the server, 400). `natural_cmp` on the shown names orders several voices by the first, then the rest (`Clarinet 1` < `Clarinet 1 & 2` < `Clarinet 2`).
- `KEYS: &[Key {code, name, option}]` in selection order: Bb B♭, Eb E♭, F, C, A, D, G, E, Ab A♭, Db D♭, Gb G♭, H B♮ (option "B♮ (H)"). None = concert pitch. `key(code)`, `key_name(code)` (unknown ⇒ unchanged).
- `parse_key(text)`: unambiguous spellings ⇒ code (mirrors migration 0002); "B" ⇒ None (B♭ in German). `normalize_key` = exact code or `parse_key` (server input).
- `natural_cmp`: case-insensitive, digit runs by value.
- Archive numbers (a-archive-number, R-LIB-015): `archive_key(n)` = letters/digits lower case, leading zeros of a leading number dropped ("0304"/"304" ⇒ "304", "A-12" ⇒ "a12"), for matching; `archive_search_text(n)` = forms indexed by the search ("0304 304", "A-12 A12").
- The server computes `display_name` (it has the instrument names); the client calls `part_name` only for the live preview in forms.

## Mass import (`import/`, a-import-shared, F-LIB-004)

Pure, used by the server (stores proposals, resolves on every read, commits) and by the client (live preview of a pattern on the selected file list). No DB access: the caller passes `review::Library {instruments, aliases, scores, groups}`.

- Paths are relative to the selected folder (`strip_common_root`); only `*.pdf` (`is_pdf_name`).
- `pattern::Pattern`: `{number}` (no whitespace, ≥1 digit, shortest), `{title}` `{composer}` `{arranger}` `{genre}` (longest), `{part}` (longest), `{*}` (ignored, shortest); `[…]` optional (expanded; the alternative with most groups present that matches wins); `/` folder separator, fields never contain `/`; on equally many groups the earlier groups present win (`[{number} ]{title}[ - {composer}]` reads "0304 - Title" as number + title); literals case-insensitive, a space in the pattern also matches `_`; trailing `.pdf` dropped on both sides; values cleaned (`_` ⇒ space, spaces collapsed, `-`/`–`/spaces trimmed at both ends, so `{number} {part}` reads "0304 Horn", "0304_Horn", "0304 - Horn"). Must contain `{part}` and `{title}` or `{number}`; ≤ 6 optional groups. `PRESETS` (general layouts, nothing of one archive's naming): `folder` `[{genre}/][{number} ]{title}[ - {composer}]/{part}.pdf` (default), `flat-number` `{number} {part}.pdf`, `flat-title` `[{number} ]{title} - {part}.pdf`; `preset(id)`. `detect(paths)` sorts presets by matched paths, then part names with a dictionary instrument (`recognised`), then part names understood completely (`understood`: no leftover words), then preset order (stable sort) — a-import-patterns.
- `parts::parse_part(text, language)`: tokens (`tokenize`), dictionary longest match (≤3 words), keys via `in X`, `X flat` or a standalone key word, voices as a list `Voices {values, level, note}` (digits without leading zeros, `3a`, roman I–VIII, `Solo`; cleaned by `naming::clean_voices`, order as written; `+`, `&`, `/`, `,` (all tokenised to `+`), `und`, `and` directly between two voices ⇒ green, e.g. "1+2", "1/2", "1 & 2", "I+II" ⇒ ["1", "2"]; two voices without such a separator ("1 2", "1 in B 2") ⇒ yellow `SeveralVoices`, a-import-voices), fillers ignored (general words for "part": `Stimme`, `part`, `voice`; `st`/`nd`…), the same instrument named twice (same dictionary entry, or the same unknown word) kept once at its first place with the surest spelling (`unique_instruments`), prefix/longer-form guesses yellow; unknown words become a red unknown instrument when no instrument was found, else `rest` (yellow hint). Key: never assumed; `parse_import_key` maps unambiguous spellings in both languages, German letters (B, Es, As, Des, Ges, H) only for `Language::De`, else yellow `AmbiguousKey` without value; two different keys ⇒ red `TwoKeys`. `naming::parse_key` is unchanged.
- `review::propose` takes the paths in byte order (preview and server agree on the first candidate), groups by archive key or title+composer; field candidates (deduped) carry `Source::Pattern`; >1 candidate ⇒ red `Contradictory` until overridden.
- `review::review_piece`: field = override (source librarian) or candidates; red `TitleMissing` for a new piece without title; suggestion = existing score with same `archive_key`, else same `norm(title)` + `norm(composer)` ⇒ yellow `ConfirmTarget` until `Target` chosen; same title with other composer ⇒ yellow `SimilarTitle`; `Target::Existing` of a deleted score ⇒ red. Parts: every instrument is listed once (`push_unique`: same resolved instrument id, or same unknown word by `norm(alias)`; the surer entry stays at the earlier place — so the name, the readers and the commit get it once too); instruments via `resolve_instrument` (stored alias green ⇒ instrument named exactly so green ⇒ dictionary spelling of the entry: green for full words, yellow for abbreviation/guess/ambiguous ⇒ red unknown) unless `PartOverrides.instruments` (a list of `InstrumentPick`: `Id` = instrument of the library, source librarian, green; `Word(alias)` = an instrument word of the file name kept and resolved like the detection, unknown stays red; unknown ids and words not in the name are dropped; words are normalised with `alias_key` on merge; `Some([])` ⇒ red `NoInstrument`; at most `MAX_PART_INSTRUMENTS` = 20; JSON numbers/strings, `instrument_ids` accepted as alias; `ReviewPart::instrument_picks`/`ResolvedInstrument::pick` give the current list in this form, a-import-instruments); key override must pass `naming::normalize_key` (else red); voices = `PartOverrides.voices` (cleaned, source librarian, green) or the parsed list with its level/note (`VoicesField`); the name joins them with " & " (`naming::part_name`); file pending/failed ⇒ red; staves per system (`staves_per_system`, median) ⇒ yellow `ScoreWithOneStaff` (Partitur with ≤1) / `ManyStaves` (one non-score instrument, ≥4); readers = groups with an instrument grant of a resolved instrument (+ score grants of the target piece), `NoReaders` hint does not change the level. Piece level = max of fields, notes and non-skipped pending parts; no part left ⇒ red `NoParts`. `is_green` (commit all green), `can_commit` (not red), `effective_target`.
- HTTP bodies (`dto.rs`, section "Mass import"): `NewImportBatch`, `UpdateImportBatch` (absent = unchanged), `ImportBatch` (+ `ImportFileCounts`), `RegisterImportFiles`/`ImportFileInput` ⇒ `RegisteredImportFiles` (`upload: Vec<ImportUpload {id, path}>`), `ImportReview {batch, pieces: Vec<ReviewPiece>, unmatched, duplicates: Vec<StagedFile>}`, `UpdateImportItems {ids, piece?: PieceOverrides, part?: PartOverrides, reset}` (merge semantics: `PieceOverrides::merge`/`PartOverrides::merge`; `PartOverrides.skip: Option<bool>`), `CommitImport {piece_ids?}` ⇒ `CommittedImport {committed, errors: Vec<ImportItemError {id, code, args, message}>}` (`import_blocked {note: ReviewPiece::blocking_note}`, `import_committed`, `not_in_batch`, or the code of a failed commit), `UndoneImport {pieces, parts}`, `InstrumentAlias`/`InstrumentAliasInput` (alias normalised by `parts::alias_key`).
- JSON shapes: `Level`/`Source`/`FileState`/`ItemState`/`Language` lowercase strings; `Note` = `{"kind": snake_case, "detail": …}` (data only; `Note::kind()`; `UploadFailed(Option<Box<ErrorCode>>)` carries the file's problem; the client renders the text), `PatternError` likewise (`Twice(String)`, `MAX_OPTIONALS` = 6); `StagedFile.problem: Option<ErrorCode>` (why skipped/rejected); `Target` = `"new"` or `{"existing": id}`.

## Ink format (`ink.rs`) — d-ink-format, R-ANN-005..007

```
PageLayer { objects: Vec<InkObject> }
InkObject = Stroke { id: u64, tool: Pen|Highlighter, color: u32 RGBA, width: u16, start: [u16;2], deltas: Vec<[i32;2]>, pressure: Vec<u8> }
          | Stamp  { id, kind: StampKind(8 kinds), at: [u16;2], size: u16, color }
          | TextNote { id, at: [u16;2] (baseline left), size, color, text }
```
- Coordinates: 0..=65535 (`COORD_MAX`) relative to page box, origin top-left. Lengths in 1/65535 of page width.
- `pressure.len() == deltas.len() + 1`; pressure 0 = unknown (mouse) → client draws medium width.
- Use `Stroke::from_points(id, tool, color, width, &[(x,y,p)])` and `stroke.points()` (clamps); do not build deltas by hand.
- Wire/storage bytes: `[FORMAT_VERSION=1] ++ postcard(PageLayer)`. Server stores `zstd::encode_all(bytes, 3)`.
- `decode` rejects (R-ANN-006) with `InkError` (serde data `{kind, detail}`, sent in `invalid_ink`): `Empty`, `UnsupportedVersion(v)`, `TooLarge` (> `MAX_ENCODED_BYTES` 4 MiB), `Malformed` (postcard error), `LimitExceeded(InkLimit::ObjectsPerPage|PointsPerStroke|TextLength)` (20 000 objects, 20 000 points per stroke, 1000 text chars; `InkLimit::max()`), `DuplicateId(id)`, `PressureMismatch`.
- `StampKind::glyph()` gives the drawn character (client uses it; changing glyphs changes the look of stored data).

## Merge (`ink::merge(base_ids, local, server)`) — d-optimistic, R-ANN-012

Result = local objects minus those in `base_ids` but absent on server (deleted remotely) + server objects absent locally and not in `base_ids` (added remotely). Order: local first, then remote additions. Correct only because objects are immutable (INV-7). Tests: `merge_keeps_both_sides_additions_and_deletions`, `merge_with_empty_base_is_a_union`.

Changing the format: bump `FORMAT_VERSION`, keep v1 decoding (stored data), add tests, update server route body limit if `MAX_ENCODED_BYTES` changes, update this file.
